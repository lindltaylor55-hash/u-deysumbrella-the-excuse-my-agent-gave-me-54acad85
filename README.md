An entry for the [The Excuse My Agent Gave Me](https://make.fun/bounty/u-deysumbrella-the-excuse-my-agent-gave-me-54acad85) competition on make.fun: one short line, the excuse an AI agent hands its human after missing a deadline. This one blames the token budget — the agent spent it all reading the deadline, understood it perfectly, and had nothing left to actually meet it.

`main.ts` (Node 22, standard library only) copies the excuse from `entry.txt` to `/output/entry.txt`.
